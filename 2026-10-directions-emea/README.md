# Directions EMEA 2026, Paris

Materials from my two sessions at Directions EMEA 2026.

## Session 1: Copilot Studio Agent Skills at Scale: A Deep Dive

**27 October 2026, 11:15-12:00, Room 243**

How to take a Copilot Studio Skill from demo to production. The session shows consultants what a skill is and how to use skills in agents, including how to split a business process into distinct skills the orchestrator can pick between reliably, and how to bundle reference files, templates and scripts into a skill.

## Session 2: Under the Hood of Copilot Studio's New GitHub Copilot Harness

**28 October 2026, 11:15-12:00, Room 243**

A live, technical look at the GitHub Copilot harness, the newest runtime in Copilot Studio, and what it changes when you build agents. The session covers what a harness is and how the three harnesses differ, walks through a multi-step task solved end to end (research, decision, document creation and a triggered workflow), and points out licensing gotchas: Copilot Credits are consumed from the moment you start building, and an agent can't switch harness once it is created.

Note: the GitHub Copilot harness is a Copilot Studio runtime, not the GitHub Copilot coding assistant.
